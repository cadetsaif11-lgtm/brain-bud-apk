# BrainBuddy — AI Study Companion

**Developed by Abdullah Saif Bin Nazrul**

BrainBuddy is an Android Jetpack Compose study companion powered by **Firebase AI Logic (Gemini)** and **Cloud Firestore**.

## Download APK (Releases)
- **Releases Page:** https://github.com/cadetsaif11-lgtm/brain-bud-apk/releases
- **Latest Release Download:** https://github.com/cadetsaif11-lgtm/brain-bud-apk/releases/latest

## How to Publish a New APK Release
1. Push this project from **AI Studio** to `cadetsaif11-lgtm/brain-bud-apk`.
2. Open the **Actions** tab on GitHub and select **Release BrainBuddy APK** (or push a Git tag such as `v1.0.0`).
3. Click **Run workflow**, enter a tag (e.g., `v1.0.0`), and GitHub Actions will build `BrainBuddy-v1.0.0.apk` and publish it under **Releases** with a direct download link.
